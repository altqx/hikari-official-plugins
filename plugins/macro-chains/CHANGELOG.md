# Changelog

## 1.0.0

- Record HikariSub commands and Automation macros, with their dialog answers, as a chain.
- Run a chain as one undo step, with every Ask field in one dialog first, from the panel or one of five shortcut slots.
- Edit each step's selection and each dialog field as Constant, Ask or Exclude.
- Import AegisubChain chains, which learn their dialogs on their first run.
- Needs a HikariSub whose plugins group their steps into one undo step; on an older one it loads and says to update.
